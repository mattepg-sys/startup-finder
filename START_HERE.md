# Start here

Paste this into a new Claude Cowork task, with this folder connected:

```
Run Startup Finder. Follow agents/00_orchestrator.md in this folder:
first-run setup if needed, show me the plan and the time estimate, then wait for my go.
```

Other useful prompts:
- `Run Startup Finder with the standard profile.` (~30 startups, ~45–60 min)
- `Show me the time estimate for the next run.`
- `Deep dive on <startup> from the last run.` (30–45 min: Europe map, strategy, red team, memo)
- `Here is my feedback from the report: <paste>` (from the report's "Copy feedback" button; it improves the next runs)
- `Set the report language to Italian.`

You can write to Claude in any language; the tool answers in yours.
