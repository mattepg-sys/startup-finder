# Changelog

## 0.1.0 (first public version)
- Early-stage focus: angel, pre-seed and accelerator deals first; never Series A or later.
- PitchBook first (≥60% of each run), with YC and other accelerator feeds as fill.
- Opportunity Cards with labels (OPEN_SPACE, DIFFERENTIABLE, TRANSFERABLE, WATCH, BLOCKED) instead of pass/kill.
- One-file HTML report with filters, "where to start", feedback buttons, light and dark themes.
- Optional onboarding, time estimate before every run, English by default with any report language.
- Validator, sealed runs, learnings loop.
